CASE STUDY / 01

Smart Plant Monitoring System

Embedded C controlling a real PIC16F18877-based sensor and alert system.

My contributionWrote the project's software
HardwarePIC16F18877
ToolingEmbedded C, MPLAB XC8
Inputs4 environmental readings

The challenge

The team needed to collect moisture, temperature, humidity and light information and present clear feedback on the physical board. Getting the DHT22 sensor code to integrate correctly was a particular challenge.

How the system works

INPUTSoil moisture
Temperature and humidity
Light
→
PROCESSPIC16F18877
Embedded C logic
Alert conditions
→
OUTPUTLCD readings
LED and buzzer alerts
Snooze and controls

Architecture summary, not a pin-level wiring schematic.

What I implemented

  • Read and processed four environmental measurements on the microcontroller.
  • Implemented LCD feedback, LED and buzzer alerts, and alert history.
  • Added a 10-second sampling cycle and 30-second alert snooze.
  • Rewrote DHT22 sensor code to resolve an integration fault.

Evidence and checks

AreaEvidenceWhat it demonstrates
Sensor outputPrototype photographLCD and seven-segment readouts visible on the physical board
Integration debuggingRecorded project contributionDHT22 sensor issue resolved by rewriting its code
Alerts and controlsImplemented system featuresLED and buzzer alerts, history and snooze

What I learned

Hardware integration rewards careful timing, incremental testing and checking assumptions at the sensor boundary. Debugging the DHT22 taught me to isolate a failing component before changing the broader system.

CASE STUDY / 04

Museum Visitor Data Explorer

Python analysis with a menu interface, CSV data and Matplotlib charts.

LanguagePython
Data inputCSV files
OutputSummary and plots
Visible years2013 to 2019

What I built

The program lets a user choose options from a console menu to inspect museum visitor numbers, compare selected years and generate charts. I split functions across Python files and used Matplotlib to display visitor trends.

Example from the screenshot

1,099,262National Museum of Singapore visitors displayed for 2019

The figure comes from the dataset displayed in the project screenshot and is not presented as a current visitor statistic.

What the evidence shows

  • Python menu options for display, statistics and plots.
  • Console output showing values for multiple Singapore museums.
  • A Matplotlib chart comparing National Museum of Singapore annual visitors from 2013 to 2019.

What I learned

Breaking analysis into reusable functions makes data processing easier to maintain, while charting helps users see patterns that are harder to notice in rows of numbers.
